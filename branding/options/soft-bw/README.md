# Soft black-and-white logo concepts

Four exploratory concepts created with the built-in ImageGen tool. Each board shows a large primary logo, a reversed version, and a standalone app-icon symbol.

5. **Soft Loop** — rounded, flowing U and an approachable lowercase wordmark. [View](05-soft-loop.png).

8. **Freeform** — flowing tapered strokes with a contemporary serif wordmark. [View](08-freeform.png).
