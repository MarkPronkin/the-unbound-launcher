# Industrial black-and-white logo concepts

Four exploratory concepts created with the built-in ImageGen tool. Each board includes a primary logo and a reversed version. These are concept images for review.

1. **Dot Portal** — an open U in circular dots with a solid technical wordmark. Recommended balance of matrix detail and legibility. [View](01-dot-portal.png).
2. **Hard Stencil** — a chamfered, cut-steel U and stencil lettering. [View](02-hard-stencil.png).
3. **Matrix Type** — circular matrix symbol and lettering. The refined board is the final option for review. [View](03-matrix-type-refined.png).
4. **Scanline** — horizontal stripes and a cut-through wordmark inspired by industrial displays. [View](04-scanline.png).

The current app artwork remains in the parent branding directory. These options have not been applied to an app build.

Full generation and refinement prompts are in [generation.json](generation.json).
